# Документация

> **[Read this in English](README.md)**

Техническая документация проекта робота Botix: реестр деталей, визуальная галерея, руководство по сборке и рекомендации для разработчиков прошивки.

## Правила написания

- **Язык**: английский. Русский — только в файлах `*.ru.md`.
- **Стиль**: нейтральный, лаконичный. Без эмодзи, без восклицательных знаков.
- **Формат**: Markdown. Преимущественно относительные ссылки.
- **Изображения**: хранятся в `assets/`, подключаются через теги `<img>`. Ширина фиксируется по контексту (150 px в таблицах каталога, 300 px в сетках галереи, 400 px для заглавного изображения).
- **Имена**: `lower_case` для деталей и якорей. Подчёркивания между словами. Без пробелов в именах файлов.
- **Даты**: `YYYY_MM` в именах папок и разделов (`2026_07_botix_uno`, а не `botix-uno-2026-07` или `07/2026`).
- **Якоря**: якорь должен точно совпадать с видимым текстом — `<a id="platform"></a>platform`. Используется для перекрёстных ссылок из других документов.
- **Проверка перед коммитом**: орфография, рабочие ссылки, отсутствие битых якорей, отсутствие ссылок на удалённые файлы.
- **Русские файлы**: каждый файл `*.ru.md` начинается со строки
  `> Машинный перевод. Возможны ошибки.` —
  до любого заголовка и содержимого.
- **Ссылка на язык**: английские файлы начинаются с
  `> **[Read this in Russian](README.ru.md)**`,
  русские зеркалят её через
  `> **[Read this in English](README.md)**`.
  Позиция: сразу после заголовка `# ...`, до остального содержимого.
- **Парность файлов**: у каждого `*.md` есть парный `*.ru.md` в той же директории.
  Добавить один без другого — значит сделать работу наполовину.
