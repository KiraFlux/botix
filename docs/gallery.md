# Botix project gallery

This gallery provides a curated visual overview of the Botix mobile robot project. It collects systematic photographs from the development process (originally published in the project's Telegram channel) and organizes them for quick reference. The images document the evolution of the robot, covering various hardware iterations, chassis assemblies, power electronics, sensor configurations, and controller boards. The gallery will be updated as new revisions and components are introduced.

## botix_power_v2_pcb_order_2026_07

New revision of the power board. After a year of use, limitations of the first version became apparent: lack of terminals, and problems with back‑EMF from servos (a large servo would "kill" a smaller one with its inductance).
Solutions: two independent channels on Mini560 PRO (5V) with 35V 470 µF capacitors on each line; terminals for direct battery voltage output (used to power motor drivers); parallel input before the switch (allows connecting an external source instead of the 3S pack); six mounting holes (3 left, 3 right); outputs now available both via terminals and Dupont headers (for servo connections).

> The version shown in the photos had a routing error - a missing trace between the two holder pads, so a red jumper wire was added on the back side. This has been fixed in the current revision available in the repository.

First version of the power board. Replaced the 18650 cells used in early prototypes with 14500 — more compact and safer for school use. Goal: simplify assembly and eliminate point‑to‑point wiring. Features: holder for 3S 14500 with direct access for quick replacement; switch breaking the negative line; two alternative footprints: either 2PH116602A or (on the reverse side) Mini560 PRO (5V) for isolated servo power; LM2596S with digital voltmeter for voltage monitoring (output set to 8V for the motor shield). This ensured stable motor speed as the battery discharged.

Based on experience from VSOSH and MOSH, a new chassis was designed to be logical and not require future rework. Key decisions: strict 20 mm grid; unified tongue‑and‑groove pattern (also grid‑aligned); frames compatible with the manipulator from the TsPM (VSOSH). Uses: ball casters (as on the VSOSH robot), off‑the‑shelf RC wheels (D52 rim, 67 mm tyre). The rear wall does not contain a holder or converter — a full power board is installed (first iteration made with toner transfer, later production ordered). First attempt to use ESP32 as the main controller. Motor driver: IArduino UNO Motor Shield. Manipulator from TsPM: MG995 for the arm, 1109 for the gripper. Uses analogue sensors from Amperka (with potentiometer sensitivity adjustment) — same as used at VSOSH 2024/2025.

Chassis inspired by the robot shown by TsPM at the Moscow practical round. Originally designed for laser cutting from 4‑mm plywood, but 3D printing proved simpler and neater. Uses printed wheels and a plumbing‑grade rubber tyre (74 mm diameter) to simulate the slipping behavior of the original olympiad robot. Frames are compatible with the TsPM manipulator, but a first iteration of a custom manipulator with two MG90S servos was developed. Drawbacks: using MG90S for the arm linkage proved unsuccessful; gripper teeth too aggressive; scale about 1.5× larger than the olympiad robot.
