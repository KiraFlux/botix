# CAD-референсы

> **[Read this in English](README.md)**

Переиспользуемые модели покупных компонентов и типовых элементов. Независимая геометрия — другие подсистемы могут ссылаться на эти файлы.

## Структура каталогов

| Путь              | Назначение                      |
| ----------------- | ------------------------------- |
| `actuator/`       | Моторы и сервоприводы           |
| `devboard/`       | Отладочные платы                |
| `sensors/`        | Датчики                         |
| `misc/`           | Колёса и другие покупные детали |
| `fasteners.fcstd` | Библиотека втулок и крепежа     |
| `cutouts.fcstd`   | Переиспользуемые вырезы         |

## Редактирование

Открывайте или создавайте файл по образцу существующих.

Файл — это либо отдельная модель, либо библиотека, перечисляющая несколько моделей.
