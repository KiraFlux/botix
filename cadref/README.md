# CAD Reference

> **[Read this in Russian](README.ru.md)**

Reusable models of purchased components and common shapes. Independent geometry - other subsystems may reference these files.

## Directory Structure

| Path              | Purpose                          |
| ----------------- | -------------------------------- |
| `actuator/`       | Motors and servos                |
| `devboard/`       | Development boards               |
| `sensors/`        | Sensors                          |
| `misc/`           | Wheels and other purchased parts |
| `fasteners.fcstd` | Bushing and fastener library     |
| `cutouts.fcstd`   | Reusable cutout shapes           |

## Editing

Open or create a file following the example of the existing ones.

A file is either a single model or a library listing several models.
