## Обзор

</div>

Проект разработан для школьных кружков робототехники, подготовки к олимпиадам (ВсОШ, МОШ, РРО) и быстрого прототипирования на хакатонах. Все детали печатаются на 3D-принтере, электронные компоненты доступны и недороги.

- Два ходовых двигателя с энкодерами (JGA25 12В, 77–170 об/мин).
- Опциональный [манипулятор с двумя степенями свободы](docs/gallery.md#botix_esp32_2026_05) (рука + захват).
- Шасси печатается ~5 часов на стандартном FDM-принтере; плоские детали, соединение шип-паз с фиксацией винтами.

<tr valign="top">
<td>

**[Модульная прошивка](botix-esp32/)** для продвинутого варианта написана на C++20 и собирается с помощью PlatformIO. Она предоставляет:

- Интерактивный CLI для настройки и отладки
- Протоколы MAVLink и RAW
- Транспорты ESP‑NOW и WiFi UDP
- Сохраняемую конфигурацию в NVS
- Модули для моторов, серв, энкодеров и LIDAR

</td>
<td>

`pybotix` – это Python-пакет для **хоста** (ПК, Raspberry Pi). Он предоставит:

- Простое и безопасное управление роботом из Python
- Поддержку роевого взаимодействия
- Высокоуровневые примитивы для навигации и поведения
- В перспективе – генерацию кода из блочных сред для обучения

</td>
</tr>

<tr>
<td align="center">

[документация_прошивки](botix-esp32/README.md)

</td>
<td align="center">


</td>
</tr>

</table>

> `pybotix` работает на хосте, а не на роботе. Он взаимодействует с роботом по протоколам MAVLink или RAW через WiFi/ESP‑NOW.

## Для кого этот проект?

</div>

- **Школьникам** – для подготовки к практическим турам олимпиад по робототехнике (ВсОШ, МОШ, РРО). Вариант на Arduino полностью соответствует регламенту большинства соревнований.
- **Студентам** – как платформа для изучения мобильной робототехники, алгоритмов навигации.
- **Участникам хакатонов** – вариант на ESP32 с прошивкой даёт готовую инфраструктуру, чтобы сосредоточиться на высокоуровневой логике.
- **Преподавателям** – для быстрого развёртывания кружков робототехники с минимальным бюджетом.

## Быстрый старт

</div>

1. Изучите [руководство по сборке](docs/assembly_guide.md).
2. Распечатайте детали из `mcad/`.
3. Для сборки электроники используйте схемы из `ecad/`.
4. - Для базового варианта: напишите и загрузите свой скетч Arduino, используя библиотеку для мотор-шилда.
   - Для продвинутого: перейдите в [`botix-esp32/`](botix-esp32/) и следуйте инструкции по сборке прошивки.

Перед началом работы убедитесь, что у вас установлено следующее ПО:

| Назначение           | ПО          | Версия |
| -------------------- | ----------- | ------ |
| САПР механики        | FreeCAD     | 1.1.x  |
| САПР электроники     | KiCad       | 10.x.x |
| Слайсер              | OrcaSlicer  | 2.4.x  |
| Сборка прошивки      | PlatformIO  | 6.1.19 |
| Среда выполнения     | Python      | 3.14.x |

> Все инструменты — свободные и открытые.
