## Обзор

</div>

Проект разработан для школьных кружков робототехники, подготовки к олимпиадам (ВсОШ, МОШ, РРО) и быстрого прототипирования на хакатонах. Все детали печатаются на 3D-принтере, электронные компоненты недороги и широко доступны.

- Два ходовых двигателя с энкодерами (JGA25 12В, 77–170 об/мин).
- Опциональный [манипулятор с двумя степенями свободы](docs/gallery.md#2026_05_botix_esp32) (рука + захват).
- Шасси печатается примерно за 5 часов на стандартном FDM-принтере; плоские детали, соединение шип-паз с фиксацией винтами.

## Аппаратная часть

</div>

### Электроника

- **Контроллер** — любая отладочная плата (Arduino UNO, ESP32 и т.п.). Конкретные модели и схема подключения описаны в [руководстве по сборке](docs/assembly_guide.md).
- **Плата питания** — собственная разработка, питание от 3×14500 (3S). Три независимых стабилизатора: 2 × Mini560 Pro (5V), 1 × модуль LM2596S (регулируемый). Варианты:
  - [Изготовление печатной платы](docs/gallery.md#2026_07_botix_power_v2_pcb_order) — заказ на производстве
  - [DIY тонерный перенос (двусторонний)](docs/gallery.md#2026_07_botix_power_v2_ttm_double)
  - [DIY тонерный перенос (односторонний)](docs/gallery.md#2026_07_botix_power_v2_ttm_single)

См. [`ecad/README.md`](ecad/README.md).

### Механика

- Все 3D-модели находятся в [`mcad/`](mcad/).
- [Основная сборка](mcad/botix.fcstd).
- [Шасси](mcad/chassis/) и [навесное оборудование](mcad/attachments).

См. [`mcad/README.md`](mcad/README.md).

### Внешние модели

- Находятся в [`cadref/`](cadref/).
- Модели покупных компонентов, используемые как референсы для проверки совместимости.

См. [`cadref/README.md`](cadref/README.md).

> Визуальные примеры разных конфигураций робота и версий аппаратной части смотрите в [галерее проекта](docs/gallery.md).

<tr valign="top">
<td>

**[Модульная прошивка](botix-esp32/)** для продвинутого варианта написана на C++20 и собирается с помощью PlatformIO. Она предоставляет:

- Интерактивный CLI для настройки и отладки
- Протоколы MAVLink и RAW
- Транспорты ESP‑NOW и WiFi UDP
- Сохраняемую конфигурацию в NVS
- Модули для моторов, сервоприводов, энкодеров и LIDAR

</td>
<td>

`pybotix` будет Python-пакетом для **хост-компьютера** (ПК, Raspberry Pi). Он предоставит:

- Простое и безопасное управление роботом из Python
- Поддержку роевого взаимодействия
- Высокоуровневые примитивы для навигации и поведения
- В перспективе — генерацию кода из блочных сред для обучения

</td>
</tr>

## Для кого этот проект?

</div>

- **Школьникам** — для подготовки к практическим турам олимпиад по робототехнике (ВсОШ, МОШ, РРО). Вариант на Arduino полностью соответствует регламенту соревнований.
- **Студентам** — для изучения мобильной робототехники и алгоритмов навигации.
- **Участникам хакатонов** — вариант на ESP32 с прошивкой даёт готовую инфраструктуру, чтобы сосредоточиться на высокоуровневой логике.
- **Преподавателям** — для быстрого развёртывания кружков робототехники с минимальным бюджетом.

## Быстрый старт

</div>

1. Изучите [руководство по сборке](docs/assembly_guide.md).
2. Распечатайте детали из [`mcad/`](mcad/). STEP-файлы для печати прикреплены к [релизам](../../releases).
3. Для сборки электроники используйте схемы из [`ecad/`](ecad/).
4. - Для базового варианта: напишите и загрузите свой скетч Arduino, используя библиотеку для мотор-шилда.
   - Для продвинутого: перейдите в [`botix-esp32/`](botix-esp32/) и следуйте инструкции по сборке прошивки.

Перед началом работы убедитесь, что у вас установлено следующее ПО:

| Назначение                | ПО         | Версия |
| ------------------------- | ---------- | ------ |
| САПР механики             | FreeCAD    | 1.1.x  |
| САПР электроники          | KiCad      | 10.x.x |
| Слайсер                   | OrcaSlicer | 2.4.x  |
| Сборка прошивки           | PlatformIO | 6.1.20 |
| Среда выполнения скриптов | Python     | 3.14.x |
| Движок рендеринга         | POV-Ray    | 3.7.x  |

> Все инструменты — свободные и с открытым исходным кодом.
