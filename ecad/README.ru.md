# Электроника (KiCad)

> **[Read this in English](README.md)**

Исходные файлы всех печатных плат Botix.

## Структура каталогов

| Путь                                | Назначение                                 |
| ----------------------------------- | ------------------------------------------ |
| `botix.kicad_sym`                   | Библиотека символов                        |
| `botix_library.pretty/`             | Библиотека посадочных мест                 |
| `botix_power_module_v2_pcb_order/`  | Под заказ на производстве (JLCPCB, PCBWay) |
| `botix_power_module_v2_ttm_double/` | Двусторонний ЛУТ                           |
| `botix_power_module_v2_ttm_single/` | Односторонний ЛУТ                          |

> Папки `ttm` подготовлены для самостоятельного тонерного переноса (бумага + лазерный принтер + утюг).

## Редактирование

Открывайте или создавайте файл по образцу существующих.

Файл `.kicad_pro` — это проект. Схемы — `.kicad_sch`, печатная плата — `.kicad_pcb`.

## Экспорт

Сгенерированные файлы не хранятся в репозитории. Экспортируйте в локальный каталог artifacts.
