# Инструменты (Python скрипты)

> **[Read this in English](README.md)**

Скрипты автоматизации для монорепозитория Botix.

| Скрипт                                     | Назначение                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| [`render.py`](render.py)                   | Рендер OBJ-модели в PNG через POV‑Ray, одна или несколько проекций за раз.    |
| [`preview_render.mak`](preview_render.mak) | Makefile: массовый рендер всех `.obj` из `artifacts/` в `artifacts/preview/`. |
| [`fixfcstd.py`](fixfcstd.py)               | Перезапись внешних путей к файлам внутри проектов FreeCAD.                    |
