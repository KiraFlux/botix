# Механика (FreeCAD)

> **[Read this in English](README.md)**

Исходные файлы всех механических деталей, сборок и основной сборки робота Botix.

## Структура каталогов

| Путь           | Назначение                                  |
| -------------- | ------------------------------------------- |
| `botix.fcstd`  | Основная сборка всего робота                |
| `chassis/`     | Детали и сборки шасси                       |
| `attachments/` | Навесное оборудование и дополнения на шасси |

> Модели покупных компонентов и общая геометрия находятся в [`cadref/`](../cadref/).

## Редактирование

Открывайте или создавайте файл по образцу существующих.

Файл — это либо отдельная деталь, либо сборка, либо библиотека, перечисляющая несколько деталей. Сборка может содержать группу с именем `printable` с деталями для печати.

## Экспорт

Сгенерированные файлы не хранятся в репозитории. Экспортируйте в локальный каталог artifacts.
